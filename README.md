# edge-ai-inference

A lightweight, offline AI inference engine for edge devices

> This project provides a practical, offline AI inference solution for edge devices, leveraging C++ for performance and OpenCV for image processing, making it suitable for applications like autonomous vehicles, industrial automation, and smart cities.

## Features

- pytest coverage of the core behaviour
- Verified by tests: Unit tests for each component: image resizing, blob creation, model loading, inference, and output parsing.

## Requirements

- Python 3.11+
- Stack: C++17, OpenCV, TensorFlow Lite

## Install

```bash
git clone <this-repo>
cd edge-ai-inference
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python -m pytest
```

Example output:

```text
Prediction: [0.1, 0.9, 0.05]
```

## Tests
